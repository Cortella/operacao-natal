# Oficina do Noel

Plataforma para criar e vender páginas de Natal personalizadas: o comprador monta a página com fotos, música e mensagem, paga por PIX ou cartão e recebe um link exclusivo para presentear alguém.

**Status:** planejamento. Nenhum código de aplicação foi escrito ainda.

O plano de desenvolvimento, dividido em 13 steps com entregas e critérios de aceite, está em [docs/ROADMAP.md](docs/ROADMAP.md). Cada step tem uma issue correspondente neste repositório.

## Stack prevista

Next.js, React, TypeScript, Tailwind CSS, PostgreSQL, Prisma, Auth.js, storage compatível com S3 e gateway de pagamento com PIX e cartão.
